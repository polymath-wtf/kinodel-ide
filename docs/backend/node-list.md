# Каталог нод

Статус: **предложение для проверки; не список реализованных компонентов.**

Создатель выбирает, кто придумывает материал, чем он генерируется и где требуется его решение. Обозначения «текст», «изображение», «видео», «аудио», «чанк» помогают ориентироваться; совместимость соединений определяется также назначением, количеством и статусом материала.

## Первая палитра

| Нода | Входы | Выходы |
|---|---|---|
| Источник текста | Текст пользователя | Именованный текст: задача, ограничение или справка |
| Источник медиа | Выбранный файл проекта | Изображение, видео или аудио с указанной ролью |
| Источник чанка | Выбранная версия персонажа, окружения или творческой памяти | Материал для явно подключённых агентов |
| Замысел / Producer | Идея, ограничения, выбранный контекст | Проверяемое описание задачи и требований |
| Storytell | Утверждённый замысел, контекст | История и последовательность сцен/кадров |
| Wardrobe | Утверждённые замысел и история, чанки персонажей/окружения, референсы | Визуальное направление и план якорей с промптами, ролями и связями |
| Генерация якорей | Проверенный план Wardrobe, требуемые референсы, выбранный workflow | Кандидаты изображений для каждого якоря |
| Выбор якорей | Полный набор кандидатов и поддерживающий план | Сохранённый утверждённый `main_frames`: по одному изображению на требуемый якорь; сохранение входит в review, без отдельной promotion-ноды |
| Storyboard | История, проверенный план Wardrobe, утверждённые якоря, контекст | Планы кадров: композиция, действие, промпты, точные референсы и их роли |
| Генерация кадров | План кадров, выбранные якоря, совместимый workflow | Кандидаты кадров |
| Согласование / выбор | Один результат или полный набор кандидатов | Решение человека; выбранные медиа становятся утверждёнными результатами |
| Настраиваемый агент | Объявленные текстовые/медиавходы, инструкции, выбранный контекст | Один результат заранее выбранного проверяемого вида |

«Генерация якорей» и «Генерация кадров» — два использования сервисной ноды генерации, а не два самостоятельных агента. Она может показывать несколько выходов, если это явно объявлено выбранным workflow.

Настраиваемый агент сначала создаёт текст или известный структурированный материал. Он не получает произвольный доступ к файлам и сети и не превращается в генератор изображений от изменения промпта. Анализ изображений доступен только с моделью, которая их принимает.

## Следующие этапы

| Нода | Входы | Выходы |
|---|---|---|
| Filmmaker | История, выбранные кадры, ограничения движения/длительности | План видеошотов и промпты движения |
| Генерация видео | План видеошотов, стартовые/другие требуемые кадры | Кандидаты видеоклипов |
| Планирование музыки / Muse | История или музыкальная задача, контекст | Музыкальный план и инструкции генератору |
| Генерация аудио | Музыкальный/звуковой план, необходимые референсы | Кандидаты аудио |
| Montage | Выбранные клипы и аудио, история, ограничения | План монтажа |
| Исполнение монтажа | План монтажа и выбранные медиа | Собранный ролик |
| Craft | Утверждённые результаты и выбранный контекст | Предлагаемый творческий чанк; публикация требует отдельного решения |
| Внешний сервис | Объявленные входы и настроенное подключение | Проверенный результат известного вида |
| Сборка набора | Именованные результаты нескольких веток | Полный упорядоченный набор; отсутствие обязательной части блокирует выход |
| Составная нода | Объявленные внешние входы внутренней схемы | Объявленные результаты внутренней схемы |

Critic — служебный агент маршрута исправления: получает точный проверяемый результат и замечания человека, возвращает ограниченное задание его владельцу или запрос уточнения. Пользователю не требуется вручную добавлять его после каждого агента. Аналогично объяснение Producer доступно из согласования и не выбирает новый маршрут самостоятельно.

## Пример соединений

```text
История + чанки персонажа/окружения
    → Wardrobe → генерация якорей → выбор якорей
                                         │
История + план Wardrobe ──────────────────┤
                                         ▼
                                    Storyboard
                                         │ план кадров + роли референсов
                                         ▼
                                  генерация кадров → выбор кадров
```

Пример генерации: `hero_face → hero_sheet(hero_face) → location`, последовательно, без промежуточного выбора; location независима и не содержит персонажей. После готовности всех изображений человек проверяет полный набор. На этом review новое лицо требует нового sheet, но сохраняет неизменённую location; новая location сохраняет лицо и sheet. Для кадра «герой бежит по улице» Storyboard использует утверждённые изображения по ролям: лицо для узнаваемости, sheet для анатомии/одежды, location для окружения. Число и состав якорей определяются историей, а не этим примером.
