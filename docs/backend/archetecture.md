Нужно собрать первоначальную архитектуру нашего пректа. 
Например факты в которых мы уверены, и отдельно то что пока не проверено и нужно заресёрчить.
Пример моего старого проекта с кучей оверинжинирных скриптов импровизированного state machine который теоретически работал, однако это были костыли, которые можно закрыть базовыми фичами в собственном приложении.
Кстате, нужно будет написать собственные `tool_cals` для агентов как раз таки для работы с нашим state machine.

# Architecture

Как базу используем LangGraph, с помощью которого мы будем составлять многоэтапные пайплайны из множества агентов.
Умеем использовать ComfyUI для генерации контента.
Можем генерировать контент через API у других провайдеров например fal.ai или openrouter.ai.
Гибридная мультимодальная память gemini-embedding-2.

Агенты не имеют доступ к компьютеру, у них будут свои `tool_calls` для создания и редактирования файлов.Ризонинг проходит на сервере у провайдеров, а локально мы получаем ответ и дальше работаем с ним.
