# Что уточнить внутри целевого Hermes

**Статус: очередь вопросов реализации.** Выбраны localhost WebUI, Kanban, фиксированный cinematic, Producer как хранитель Brief и помощник по правкам, четыре review. ComfyUI — default: Krea2 txt2img, Qwen img2img, MiniMax H3 img2vid; ref2vid — #future. Эти решения не переоткрываем при исследовании.

## Вопросы и предпочтения

| № | Что выяснить у Hermes | Предпочтение / рекомендация |
|---|---|---|
| 1 | **Кто выполняет переход этапа?** Как сохранить approval, завершить task и создать следующую без дубля, включая restart между действиями? | Небольшой фиксированный обработчик plugin на поддержанных host-механизмах; не второй scheduler. Конкретный механизм выбираем внутри Hermes |
| 2 | **Как одна карточка объединит план, долгий render и review?** Кто владеет task, когда LLM уже завершён, но tool ещё работает; как предотвращается повторный dispatch? | По возможности одна stage task, без удержания LLM turn. Если host требует отдельную tool task — явно описать mapping, UI по-прежнему показывает один этап |
| 3 | **Где обязательная проверка результата?** Какая поддержанная точка принимает output и не позволяет `kanban_complete` обойти schema/domain validation? | Один контролируемый путь публикации: проверить → сохранить revision → открыть review. File/tool/final-answer transport выбрать по установленному API; не доверять одному статусу worker |
| 4 | **Где хранить связи и решения?** Как атомарно сохранять input snapshots, revisions, approvals, task bindings и reservations? | Сначала host storage; при пробеле — только узкие metadata плагина. Полные JSON и originals принадлежат проекту, не scratch/cache. Не копировать Kanban DB и transcript store |
| 5 | **Какие действия доступны в обоих UI?** Как реагировать на native complete/reopen, изменение модели или удаление attachment? | Общий просмотр прогресса обязателен. Объём управления из Hermes UI ещё не выбран; до решения обычный `done` не означает creative approval и не выпускает downstream |
| 6 | **Как подключить выбранный ComfyUI-профиль?** Проверить точные workflows, 2/3-image roles Qwen, geometry, MiniMax timing/audio, upload/import и per-production settings без изменения чужих запусков | Переиспользовать [workflow-карту](hermes-kinodel-render.md#comfyui-профиль-по-умолчанию); сохранить версии/receipts. fal.ai — явный альтернативный путь, без auto-fallback; ref2vid вне MVP |
| 7 | **Как продолжать после ошибки/отмены?** Различить невалидный output, отказ провайдера, unknown submit, partial results, поздний результат и повтор доставки | Короткая таблица error → allowed action; успехи сохранять, неизвестный заказ сначала сверять. Уточнить host attempt/cost limits, не создавать общий budget engine |
| 8 | **Как ограничить tools workers?** Можно ли оставить чтение нужных inputs, публикацию своего результата и сообщение ошибки, исключив terminal/code, создание задач и произвольное делегирование? | Проверить реальные profile/plugin permissions и область Kanban config. Prompt — дополнительное правило; отключение auto-decompose само по себе недостаточно |
| 9 | **Как продолжить прежнюю worker session и задать вопрос специалисту?** Какой вызов сохраняет task/claim/attempt связь? Как выполнить «Вопрос» без новой revision, «Правку» — с новой? | Пользователь сообщил, что уже проверил продолжение старой worker session внутри Kanban lifecycle. Выясняем точный механизм и ограничения, не наличие функции. Не путать creator session с worker session и не запускать конкурентный turn |
| 10 | **Как установить, запустить и обновить пакет?** Кто раздаёт React, запускает web-слой, выбирает port/data root, хранит ключ и открывает браузер? Как восстановить работу при недоступном Hermes и обновлении? | Одна поддерживаемая локальная конфигурация; ключ остаётся на сервере, проверяется доступ к actions/media. Запуск фиксирует workflow/instruction versions; обновление не меняет подготовленные inputs |

## Отдельные уточнения схем

Обязательные поля, enum, единицы, links/coverage/order, допустимые revise-изменения и provenance — в [вопросах к JSON Schemas](hermes-artifact.md#что-уточнить-перед-исполняемыми-json-schemas). Граница правки уже выбрана: после фиксации входа зависимой операции нужна новая production, даже до фактического запуска worker.
