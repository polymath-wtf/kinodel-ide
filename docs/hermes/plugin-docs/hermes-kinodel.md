# Kinodel для Hermes — пакет препродакшна

**Статус: препродакшн.** Описываем будущий плагин; финальная архитектура и интеграция с установленным Hermes ещё не проверены. Это отдельное направление, не миграция standalone Kinodel.

## Что получает автор

Отдельную студию в браузере на localhost: чат с Продюсером, нодовый производственный маршрут, раскадровку и историю материалов. Hermes предоставляет агентный runtime, разговоры и инструменты; Kinodel добавляет правила кинопроизводства и интерфейс.

Продукт нужен автору, который хочет превратить замысел в фильм с командой узких AI-специалистов, не собирая вручную ответы, prompts и файлы между чатами. Pipeline показывает, кто работает и какого решения ждёт; Canvas позволяет сравнивать образы, кадры и клипы; инспектор раскрывает входы, настройки и историю выбранного материала.

**Плагин — это фиксированный производственный шаблон, инструкции специалистов, контракты данных и React WebUI поверх Hermes Kanban.** Kanban хранит реальные задания и запускает исполнителей: прогресс виден и в Kinodel, и в штатном интерфейсе Hermes. Свой агентный runtime или независимую копию task DB не строим.

```text
Идея → Producer / preproduction → подтверждённый brief
→ Storytell → review истории
→ Wardrobe → anchor generation → review anchors
→ Storyboard → frame generation → review frames
→ Filmmaker → video generation → review videos
→ Montage → финальный MP4
```

Producer — основной собеседник на всём маршруте. Он собирает недостающие сведения, обновляет бриф, объясняет результаты и передаёт правки специалисту. Автор утверждает конкретные результаты; готовый файл сам по себе не означает согласование.

После опроса Producer сохраняет полный `brief.json`; изменения становятся Brief v1 → v2 → v3, без отдельного draft-документа. Wardrobe, Storyboard и Filmmaker получают **полную утверждённую Story**, а не только отдельные characters/locations/shots. В каждом результате видны исполнитель и происхождение; `completed` ещё не означает approval.

Default-производство — ComfyUI: Krea2 txt2img, Qwen multi img2img, MiniMax H3 img2vid. В MVP три anchors: по одному portrait и location, затем character_sheet из этих двух изображений. Конкретные workflows — [render](hermes-kinodel-render.md#comfyui-профиль-по-умолчанию); ref2vid отложен в #future, fal.ai остаётся явной альтернативой.

### Короткий путь автора

1. Обсудить идею с Producer, выбрать героев, место, визуальное направление, длительность, число шотов и условия генерации.
2. Подтвердить brief. Workflow создаёт задания по шаблону; Producer не решает самостоятельно, кого запускать дальше.
3. Смотреть результаты и видимые связи данных: например, какие персонажи Story переданы Wardrobe и какой frame использует видео.
4. Утвердить этап или адресовать замечания его специалисту — напрямую в панели этапа либо через Producer. Новый ответ сохраняется отдельной версией.
5. При необходимости сделать дополнительные дубли через Generate, выбрать нужные и получить финальный фильм.
6. Вернуться к истории или начать новый запуск на основе старого brief, сохранив прежние материалы.

### Предсказуемость и сохранность

Маршрут и условия переходов определены заранее. Каждый специалист получает structured input, возвращает structured output своего этапа и останавливается. При проблеме он сообщает ошибку или нехватку данных, а не чинит код/окружение и не берётся за чужую задачу. Typed bindings видны в интерфейсе; backend разрешает их в конкретные версии, а не в произвольный «последний файл».

Полные результаты и originals сохраняются независимо от сжатия чата. Выбор дубля, согласование и завершение Kanban task — разные факты. Producer не должен ждать всех workers; их жизненным циклом управляет Kanban dispatcher, переходами — plugin workflow.

Правку можно применить в текущем производстве с новым review, пока результат не закреплён в prepared input зависимой операции. После этой границы создаётся новое связанное производство; подготовленные входы не заменяются даже до старта worker.

В MVP пять агентов, один герой, одна локация, четыре производственных review и отдельное подтверждение брифа перед запуском. Изображения по умолчанию 1024×1024, видео 480×480. Montage — инструмент. Маршрут фиксирован; React Flow показывает связи, но не является конструктором исполняемых графов. Короткие инструкции пяти ролей — [hermes-agents](../hermes-agents/README.md).
