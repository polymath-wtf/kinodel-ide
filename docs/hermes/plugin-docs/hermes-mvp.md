# Cinematic MVP — минимально рабочий плагин

**Статус: целевой объём препродакшна, ещё не реализованный продукт.** Порядок разработки — в [roadmap](hermes-kinodel-roadmap.md).

## Путь автора

1. Открыть localhost WebUI, создать проект и написать идею Продюсеру.
2. Ответить на вопросы Producer: история, персонаж, локация, визуальное направление, длительность, число шотов, размеры/aspect, качество видео и image/video profiles. После опроса получить полный Brief; изменения — новые версии. MVP использует один portrait, одну location и один character_sheet; идея без героя или с дополнительными героями/местами требует явного согласования покрытия, не молчаливого удаления обязательных anchors.
3. Прочитать собранный brief и подтвердить запуск. Несовместимые длительности/размеры выясняются до генерации; Producer предлагает варианты, автор выбирает.
4. Пройти Storytell → Wardrobe/anchors → Storyboard/frames → Filmmaker/videos. После каждого завершённого производственного этапа посмотреть результат и утвердить его либо попросить правки через Producer.
5. При необходимости открыть конкретный кадр/клип, изменить prompt или поддерживаемые настройки, нажать **Generate**, выбрать понравившийся дубль и затем утвердить набор этапа.
6. Получить локальный MP4 из всех утверждённых клипов в порядке истории. Открыть материалы и после закрытия браузера или отключения провайдера.

## Что входит

Исполнительная основа — Hermes Kanban: реальные stage tasks видны и в Kinodel, и в штатном UI Hermes. Plugin создаёт их по фиксированному workflow, не через свободное планирование Producer. У специалистов проверяемые structured input/output и видимые field bindings; при проблеме — ошибка или запрос данных, без ремонта кода и чужих задач.

| Функция | Результат для автора |
|---|---|
| Пять рабочих агентов | Producer ведёт brief и общение; четыре специалиста исполняют Kanban-задания workflow |
| React Flow pipeline и Canvas | Видны маршрут, образы, шоты, дубли и место ожидания решения |
| Четыре review | Принимается точная история или полный выбранный набор; планы доступны без дополнительных обязательных gates |
| Автоматическая генерация и manual render | Один маршрут генерации; ручной дубль не требует LLM |
| ComfyUI default / fal.ai | Основной путь: Krea2 txt2img, Qwen multi img2img, MiniMax H3 img2vid. fal.ai — явно выбранная настроенная альтернатива; ref2vid после MVP |
| История и адресные правки | Brief revisions, результаты, prompts/settings и автор результата доступны; feedback можно направить специалисту. Пользователь подтвердил resume прежней worker session; способ интеграции уточняется |
| Новый запуск из старого | Можно взять прошлый brief, изменить героев и пройти новый маршрут, сохранив прежний фильм |
| Возвращение в проект | Сохранённые результаты открываются без повторной генерации; неизвестный заказ не отправляется заново молча |

MVP означает полный cinematic, а не только картинки. Первый сквозной проект проходит выбранный ComfyUI-путь: portrait + location → character_sheet → frames → img2vid → Montage. Поддержка fal.ai подтверждается отдельно; наличие файлов workflows не доказывает готовую интеграцию Hermes.

## Когда считаем готовым

Автор проходит весь путь без ручного переноса ответов между агентами. Правка истории создаёт новую версию на review; генерация создаёт новый дубль; выбор не затирает старые файлы. Повтор доставки команды не создаёт дополнительный заказ. После restart видны сохранённые версии и корректное доступное действие. Финал проверен по формату, длительности и отсутствию аудио.
