# Минимальный MVP

**Статус: кандидат для обсуждения с Hermes, не утверждённый план сборки.**



## Cinematic pipeline mvp

Первый MVP — небольшой нодовый Dashborad, с готовым маршрутом Cinematic и удобным просмотром материалов. Ручное добавление нод, редактирование связей и вайбкод произвольных маршрутов — #future. Mvp будет готово когда пользователь может пройти полный cinematic pipeline с нуля.

Kinodel breaks production pipelines into clean stages:
- Cinematic pipeline with stages like:
```text
brief with producer (hermes chat)
→ producer → brief.json
→ storytell → story-hitl
→ wardrobe → anchor-gen → anchor-hitl
→ storyboard → frames-gen → frames-hitl
→ filmmaker → video-gen → video-hitl
→ montage → final
```

## Минимальные возможности

- Базовые ноды для сабагентов (producer, storytell, wardrobe, storyboard, filmmaker, montage).
- Доска с упорядоченными кадрами, детали результата.
- Связанные с проектом материалы, локальное сохранение и повторное открытие.
- Прямой render из UI, если существует безопасный поддерживаемый путь; иначе сначала проверяем его отдельно.

Доступ к child-чатам желателен, но не повод строить собственную систему чатов. Сначала проверить штатный backend Hermes.

## Проверка полезности

Автор после перезагрузки Hermes, заходит в артефакт/проект, видит свои материалы и проделанную работу. Личные Hermes-чаты не появляются в проекте. Невалидный ответ не превращается в принятое описание кадра. Повтор или ручной render не требует пересказывать проект агенту и поднимать чат. Повтор доставки команды или потеря ответа не запускают незаметно второй заказ.

Какие из этих свойств уже обеспечивает Hermes, а какие требуют тонкой логики плагина,надо выяснить до реализации. Отдельно проверить restart выполняющегося задания: сохранённый чат не доказывает восстановление заказа.

## #future

Ручная сборка и редактирование нод/связей, вайбкод произвольных маршрутов, полный video/montage editor, анализ музыки, chunks и расширенный retrieval. Не добавляем generic runtime, LangGraph или новую DB «на будущее».
