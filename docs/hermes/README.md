# Kinodel × Hermes

**Статус: препродакшн плагина.** Отдельный localhost WebUI поверх backend Hermes. Реализация и финальная архитектура ещё не подтверждены; standalone Kinodel остаётся отдельным действующим проектом.

Автор начинает с чата Продюсера, собирает brief, проходит историю → образы → кадры → видео → монтаж и утверждает результаты. Минимальный плагин переиспользует runtime и tools Hermes, добавляя рабочее пространство и правила производства.

Исполнение выбрано через **Hermes Kanban**: фиксированный workflow создаёт задачи, dispatcher запускает специалистов; прогресс доступен в нашем и штатном интерфейсах. Producer хранит brief и помогает с правками, а не самовольно управляет цепочкой. Structured input/output и видимые связи полей описаны в [контракте артефактов](plugin-docs/hermes-artifact.md).
