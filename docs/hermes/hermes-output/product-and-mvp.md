# Продукт и границы cinematic MVP

**Требование:** творческое рабочее пространство, в котором автор управляет промежуточным содержимым, а не только пишет запрос и ждёт MP4.

## Путь автора
1. Обсудить идею с Producer; прикрепить выбранные референсы из своей wiki или материалов проекта.
2. Получить полный Brief, проверить точную версию и подтвердить запуск.
3. Прочитать Story, запросить правки или утвердить её.
4. Сравнить anchors, выбрать совместимый набор и утвердить образы.
5. Проверить opening frames всех шотов и утвердить раскадровку.
6. Посмотреть непрерывные видеоклипы, выбрать дубли и утвердить набор.
7. Получить собранный MP4 и открыть историю его происхождения.

Producer остаётся в чате на всём маршруте. Нода Brief показывает документ, а не отдельного «Producer-исполнителя». Обсуждение, выбор и approval — разные действия.

## Минимальный законченный продукт
| Область | Целевой объём |
|---|---|
| Маршрут | Один фиксированный `Cinematic.pipeline`; регистр имени файла/идентификатора ещё не выбран |
| Команда | Producer и четыре специалиста; Montage — инструмент |
| Масштаб | По исходному концепту один герой и одна локация |
| Anchors | Portrait, location, character_sheet; дополнительные дубли допустимы |
| Контроль | Подтверждение Brief и четыре производственных review |
| UI | Producer chat, Pipeline, Canvas, библиотека/история материалов, общий инспектор |
| Правки | Полные revisions, адресный feedback, Generate без обязательного LLM, Select отдельно от Approve |
| Сохранность | Локальные originals, точные inputs, возвращение в проект без повторной генерации |
| Финал | По исходному концепту немой MP4 из полных утверждённых клипов в порядке Story |

Два шота — размер первой сквозной приёмки, не максимальное число шотов продукта. ComfyUI — выбранное в концепте основное направление; конкретные модели и размеры пока не доказаны установленной интеграцией.

## Не входит в MVP
Произвольный graph editor, свободное планирование командой, собственный scheduler/runtime, копия Kanban DB, Critic, музыка/голос, timeline-монтаж, ref2vid, автоматическая выборочная пересборка downstream, merge производств, собственный RAG или summarizer. fal.ai — явная альтернативная интеграция, не скрытый fallback и не условие первой ComfyUI-приёмки.

## Продуктовый критерий успеха
Автор может объяснить, **что сейчас создаётся, кем, из каких утверждённых материалов и какое решение требуется от него**. Он не переносит ответы между агентами вручную и не теряет прежние результаты при правке.
