# Материалы проекта

**Статус: требования к удобству и сохранности; формат хранения открыт.**

## Компактная основа проекта

Проект хранит замысел и ссылки на актуальные выбранные материалы — source of truth, который не зависит от полноты текущего чата.

- **Brief:** пожелания автора, формат кадра, предполагаемые число кадров/длительность, настройки выбранного render и явно добавленные персонажи, стиль, wiki/references.
- **История:** выбранная версия текста и, при необходимости, главы.
- **Образы:** важные для следующих специалистов решения о персонажах, одежде, стиле и назначении референсов.
- **Раскадровка:** последовательность кадров и выбранные материалы.
- **Видео/final:** ссылки на выбранные клипы; формат итоговой сборки уточняем по сценарию, а не требуем mp4 для любого проекта.

Это логические разделы, не требование хранить всё в одном файле или заранее делать все стадии MVP.

## Подробности отдельно

Prompts, seeds, workflows, параметры, варианты и большие structured outputs сохраняются рядом с материалами. Сводка ссылается на них; агент читает подробности только для нужной задачи. Prompts не считаем временными: они нужны для просмотра, правки и воспроизведения генерации.

Wiki подходит для знаний и авторского смысла. Локальное чанкирование — #future. Чаты по возможности остаются в штатном хранении Hermes. Нужен ли собственный manifest/журнал или хватает существующих записей — вопрос для Hermes, не принятое решение о новой DB.

## Запись и правки

Хотим принимать и сохранять проверенный результат автоматически, без дополнительного LLM turn ради ручного редактирования большого файла. Специалист получает компактную задачу; сохранение связывает его результат с проектом и точными входами.

Новая версия не затирает прежнюю. Сводка показывает выбранную версию, а авторское принятие фиксируется отдельно от факта создания файла. Правка истории не означает автоматический рендер всех последующих кадров.
