# Архитектура: сначала переиспользование Hermes

**Статус: гипотезы для проверки, не выбранный стек.** Ядро продукта — [hermes-kinodel.md](hermes-kinodel.md).

## Предлагаемая граница

```text
Автор → Kinodel UI: доска, раскадровка, чат, параметры, выбор дублей
                   ↕ поддерживаемая поверхность Hermes
          Продюсер → специалисты + skills → инструменты
                   ↕
          Локальная библиотека проекта и сохранённые результаты
```

Hermes — первый кандидат на управление заданиями, беседами, контекстом и инструментами. Плагин отображает материалы и даёт автору точные действия. Тонкая логика Kinodel связывает проект, результат, параметры и выбор автора там, где Hermes этого не обеспечивает.

## Не назначаем заранее

- Не выбираем LangGraph, отдельный сервис, собственную DB, MCP или HTTP-мост до проверки существующих поверхностей.
- React — желаемая технология UI, но способ упаковки зависит от поддерживаемого plugin SDK.
- Не считаем заранее известной долю готового backend. Просим Hermes назвать конкретные переиспользуемые механизмы.
- Не переносим весь backend standalone Kinodel. Реализация и деплой планируются в среде Hermes после согласования минимальной схемы.

## Что нужно обеспечить независимо от реализации

Результат принадлежит точному проекту и заданию. Выбор автора не путается с завершением агента. Правка не стирает старый дубль. Одно действие не запускается одновременно двумя владельцами. Неизвестный исход платного заказа не разрешает автоматический повтор.

Это требования к поведению, не требование строить отдельную state machine. Сначала проверяем, как их покрывают существующие Hermes APIs, tools и хранение; затем добавляем только отсутствующее.

## Решения после ответа Hermes

1. Выбрать одну оболочку UI и один поддерживаемый путь взаимодействия.
2. Назначить одного владельца выполнения маленького маршрута; выяснить, подходит ли native orchestration или `/goal`.
3. Выбрать минимальный способ сохранять результаты и параметры, не раздувая context.
4. Проверить прямой render из UI с тем же учётом результата, что у агентного вызова.
5. Только при доказанном пробеле рассмотреть [LangGraph-вариант](langgraph-hermes.md).

Вопросы, включая restart, права доступа и безопасность plugin code, собраны в [hermes-questions.md](hermes-questions.md). Детали кода определяем по целевой установке, а не по предполагаемой внутренней архитектуре.
