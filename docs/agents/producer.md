# Producer

Class: optional user-facing creative assistant. Status: **Deferred from the fixed cinematic MVP**.

Cinematic begins with a submitted user Brief, not a compulsory Producer call or Brief approval loop. The input form/API validates visible defaults and selected context before Run. [Brief ownership](../backend/artifacts.md#brief-and-story-boundary) defines that boundary.

Producer can later help a creator formulate a brief, resolve missing requirements or summarize progress. It must show proposed assumptions/settings before submission, preserve raw intent and never invent approval. Narrative invention belongs to Storytell.

Review questions and edits in MVP go to the current result's owner. Producer does not intercept those conversations, select graph edges, submit render jobs or replace specialist results. Exact future modes/schemas are defined when this assistance is activated.
