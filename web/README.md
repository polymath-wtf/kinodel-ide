# Kinodel cinematic prototype

Open `index.html` directly in a browser. No installation, build, server or network access is required.

- Wheel zooms around the cursor; middle-button or empty-canvas drag pans. Drag a card by its header. `Fit` and `Current stage` help navigate.
- Single-click a node/image for its inspector; double-click to enter. On Canvas, right-click an asset to open its production stage (anchors → Wardrobe, images → Storyboard, video → Filmmaker), or empty field to return to the last Pipeline scope and viewport. In other nested scopes, right-click goes up one scope. Inputs and inspector retain their native context menu. Keyboard: Enter opens details, Shift+Enter enters a nested node, Shift+F10/Context Menu on a Canvas asset opens its production stage; rail and breadcrumbs also navigate without a mouse. Each scope retains its layout until reload.
- Brief separates the read-only submitted example from a local new-run form (idea, explicit references, demo character choices and visible example output settings). Save validates nonblank text but never submits or changes the current run; draft fields persist across navigation until reload.
- Left navigation: **Pipeline / Canvas / Brief / Review / Montage** (bottom navigation on mobile). Pipeline retains seven stages including Final as Montage's output. Green checks mark completed Brief/Storytell, orange marks the current Wardrobe review. L0 ports summarize stage inputs and results while arrows show review order, not data wires. L1 ports name exact plan/media/review handoffs; contextual refs/profiles are labeled but not linked to invented stages. **View in Canvas** opens the matching project-media filter.
- **Canvas** is the single media workspace: exactly three unboxed horizontal rows, Anchors (3), Images (9 start-frame attempts), Video (2 pending clips). At 1600×1000 and 1440×900 all 14 fit at default/Fit with the inspector closed: desktop cards are ~150px and ~136px wide respectively. With the inspector open cards stay at least 120px wide at 100% Fit; pan to reach the far end of the Images row rather than shrinking or wrapping. Truncated labels retain full accessible names and hover titles. `New shot · coming soon` is disabled. Filter All media / Anchors / Images / Video. Click or press Enter on a card for details, then **Open in workflow**; double-click or Shift+Enter opens its ComfyUI API-prompt projection from `workflow/comfyui/` (selected nodes only). The header breadcrumb returns to the filter and viewport. Pending clips are not playable.
- Media cards move independently by their headers; Canvas is a gallery without wires or sockets. Portrait → wardrobe sheet lineage is available in the inspector. Provider workflow sockets/wires still attach to mapped API output indices and target inputs. Every workspace surface uses the supplied `docs/frontend/refs/zbs ref v1/background v2.png` without an extra dot grid. Mobile pans across the authored rows.
- Header **Pipeline / Chat** switches between the workspace and chronological production feed, preserving scope/viewport and local message draft. Chat shows the submitted idea, collapsed approved Story, optional visual direction and one anchor result. Image clicks open the same Canvas inspector; **Review anchor set** opens the existing review details. **Ask / Request changes** explicitly addresses Wardrobe about set 2 / r4; **Save draft** adds an unsent local message until reload. No simulated agent reply or approval.
- All four creative roles use one `llm-agent` shell with role-specific system-prompt configuration. Its interior illustrates `START → Model → END`, with conditional `Model → ToolNode → Model` for one proposed read-only `read_selected_reference(alias)` tool. Instructions/model settings are configuration, not executable nodes; validation/saving is outside the loop. This is a design specimen, not the currently integrated backend agent. Pattern: [LangGraph quickstart](https://docs.langchain.com/oss/python/langgraph/quickstart), [ToolNode loop](https://docs.langchain.com/langsmith/trace-with-langgraph#3-log-a-trace).
- Media inspector defaults to a contained preview, honest stock/waiting status and useful prompt/local seed. Mapped technical values are behind **Settings**, explicitly marked example API prompts rather than actual render receipts; identity/dependencies live in **Lineage**. Frame prompt/seed drafts survive navigation; `Regenerate · mock` queues locally only. On mobile the inspector is a full-screen sheet.

All outputs, statuses and prompts are **mock data**. Montage is a pending two-shot timeline with illustrative scrub/selection and no fake playback/export; its eventual Final stays on Pipeline. Workflow diagrams use real API node IDs, class types, source output indices and target input names; socket type labels are UI descriptions, not provider schemas. These are partial projections of unaudited provider files, not registered profiles. No backend, job execution, approval or agent messaging is connected.

Photographs in `assets/` are illustrative stock images, not a consistent generated character: [portrait](https://images.unsplash.com/photo-1534528741775-53994a69daeb?fm=jpg&w=720&q=82&fit=crop), [wardrobe](https://images.unsplash.com/photo-1544022613-e87ca75a784a?fm=jpg&w=720&q=82&fit=crop), [coast](https://images.unsplash.com/photo-1518837695005-2083093ee35b?fm=jpg&w=1000&q=82&fit=crop).
