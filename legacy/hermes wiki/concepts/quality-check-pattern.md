# Quality Check Pattern — Два уровня проверки качества

Задача в том, чтобы проверять качество сгенерированного контента на двух уровнях: техническом и визуальном.Нужно отправлять промежуточные результаты критику который по сабжу разложит что и где можно подправить. Например править сценарии (сюжетные ляпы, диалоги), править визуал (кадры, стили, атмосферу), текст песни (ритм, рифму, смысл).

Два уровня QC: техническая (metadata) и визуальная (VLM). Автоматизирует контроль качества сгенерированного контента.

## Уровень 1: Языковая проверка

Проверить текст на кино ляпы, сюжетные дыры, диалоги, и тд. Тоесть мы сгенерировали например сценарий, и мы сразу отправляем его на проверку критику, в ответ получаем сразу предложения по правкам, которые можно принять или отклонить, затем идём дальше и тд.

## Уровень 2: Визуальная проверка (VLM)

Нужна будет — агент ВИДИТ результат и оценивает:
- Соответствие промпту
- Style consistency между шотами
- Качество (артефакты, искажения, нечёткость)
- Содержание (что на кадре, персонажи, атмосфера)
- Атмосфера (настроение, цвет, освещение)
 и тд хз что ещё может реально увидеть агент, смотря какая vlm канеш.

## Когда проверять

- **Phase 1**: Автоматически после генерации сценария,сюжета,или других текстов.
- **Phase 2**: автоматически в конце генераций картинок или видео.

## Действия при проблемах

| Ошибка | Действие |
|--------|----------|
| Missing shot | Предупредить, продолжить без него |
| Wrong resolution | `compose` auto-fixes через re-encode |
| VLM: bad quality | Переформулировать prompt, retry (max 2) |
| Corrupted file | Retry compose |

## Error Recovery в Agent Workflow

| Ошибка | Действие |
|--------|----------|
| Image gen failed | Retry 1 раз. Если fail → skip шот |
| Video gen failed | Retry 1 раз. Если fail → skip шот |
| VLM says bad quality | Переформулировать prompt, retry. Max 2 retries |
| All images failed | СТОП. Спросить юзера |
| Budget exceeded | СТОП. Уведомить о лимите |
