# Летний мазик

**Летний мазик** — кулинарный хак: берёшь любимый домашний летний салат, выжимаешь из него соки, постепенно добавляешь крахмал и взбиваешь миксером, пока консистенция не станет похожа на мазик.

## Фичи

- **Маёнезница одноразовая:** можно купить с Китая пакет / дозатор для мазика.
- **Кликбейт рилса:** «Летний мазик, скоро на всех полках галактики».
- **Zero-waste сок:** фишка в том, чтобы из вкуснейшего сока, который остаётся от летнего салата, сделать соус / мазик вместо того чтобы выливать.
