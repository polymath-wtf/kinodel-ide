# Temki Index

`temki/` — база идей для лутания денег: активные и пассивные источники, где [[llm]]/AI agents могут брать на себя исследование, генерацию, публикацию, аналитику и операционку. Папка нужна как отдельный слой wiki, чтобы не смешивать денежные гипотезы с обычными [[project-kinodel|проектами]] и [[ai-influencer-monetization|монетизацией инфлюенсеров]].

## Правило упаковки темки

Каждая темка начинается с основного файла `temki/<name>.md`, а всё, что раздувает контекст, выносится в дочерние файлы `temki/<name>-*.md`. Основной файл должен отвечать на вопрос «зачем это делать и как выглядит money loop», а дочерние файлы — хранить ниши, roadmap, монетизацию, production rules, SEO, tone of voice, risks и agent workflow.

## Темки

- [[dzen]] — ведение каналов Яндекс Дзен с помощью нейросетей и AI agents: ниша → конкурентная разведка → система стиля → batch статей → публикация → метрики → монетизация.
- [[kronos]] — Kronos foundation model для financial K-lines как temka для crypto/algo-trading research: zero-shot прогнозы, fine-tuning на свежих свечах, walk-forward backtests, signal API/dashboard и agent workflow.
