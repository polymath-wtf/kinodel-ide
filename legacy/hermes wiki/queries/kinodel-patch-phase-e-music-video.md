## Objective

Add music-video as the first music-spine pipeline, with Muse using real `music_chunk` RAG rather than ordinary artifact dumps.

## Scope

Create/modify:

- `pipeline-kinodel/pipelines/music_video.v1.json`
- Muse capability contract and skill references
- `music_request.json` / `music_result.json` contracts
- `render-kinodel/adapters/registry.json`
- render/audio adapter for Suno-compatible provider-neutral mapping
- dynamic result promotion for music stages if needed

May update:

- `render-kinodel/scripts/render.py`
- `render-kinodel/references/*` for audio/music provider ownership
- storyboard/filmmaker contracts for timed units

Do not modify:

- Phase RAG internals except failing regressions;
- create-pipeline or renovation_timelapse;
- Muse into a provider caller;
- planner artifacts to contain raw provider payloads.

## Core implementation requirements

### 1. `music_video.v1` route

```text
p0_music_briefgate
→ resolve_context_pack: consumer=muse-kinodel profile=muse_inspiration_balanced
→ p1_muse: muse writes muse_output.json + music_request.json
→ p2_music_render: render/audio adapter writes outputs/music.mp3 + render_results/music_result.json
→ p3_style_frame_plan: wardrobe writes style frame using muse_output + selected chunks
→ p4_music_style_gate: approve music + style frame, hard stop
→ p5_timed_storyboard_plan: storyboard writes timed image prompts from lyrics/sections
→ p6_timed_images_render
→ p7_music_visual_gate, hard stop
→ p8_timed_video_plan
→ p9_timed_video_render
→ p10_music_montage
→ p11_music_video_chunk / cinema_chunk
```

MVP limit:

- 15–30 seconds;
- 5–8 image prompts before scaling.

### 2. Muse RAG handoff

`context_pack` profile:

```json
{
  "consumer_agent": "muse-kinodel",
  "profile": "muse_inspiration_balanced",
  "max_context_tokens": 6000,
  "include": ["music_inspiration", "optional_avatar_context", "optional_cinema_style_context"]
}
```

Context pack includes:

- `music_chunk_id`, title, tags;
- ALM summary;
- energy curve and section/timing notes;
- compact generation hints;
- audio path as ref, not inline blob;
- copyright/safety rule against melody/lyrics cloning.

Optional `muse_audio_deep` uses 1536/3072 only for top-candidate audio rerank.

### 3. Muse ownership

Muse may write:

- `muse_output.json`
- `music_request.json`
- lyrics / lyric sections
- music prompt
- style tags / vibe DNA
- timing skeleton
- selected `music_chunk` refs

Muse must not call fal.ai/Suno/ComfyUI directly.

Render/audio adapter writes:

- `outputs/music.mp3`
- `render_results/music_result.json`

### 4. Provider-neutral `music_request.json`

Allowed fields:

- `schema`
- `project_id`
- `status`
- `stage: music_render`
- `adapter_profile` or registry key
- `jobs[]`
- `lyrics`
- `prompt`
- `style`
- `title`
- `instrumental`
- `duration_target_seconds`
- `model_preference` only if registry-mapped/provider-neutral enough

Forbidden fields:

- API keys;
- callback URLs unless generated by Render runtime;
- queue IDs;
- raw provider responses;
- retries/costs/logs.

### 5. Timed visual handoff

Storyboard/Filmmaker/Montage use timing from `muse_output.json`, `music_timing.json`, and `music_result.json`. Timing windows are source-derived from Muse/music analysis, not invented provider defaults.
